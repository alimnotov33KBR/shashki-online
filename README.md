# Шашки v5.2.0 Online PRO — NA STUDIO

Версия на базе стабильной v5.1.9.

## Новое
- Внизу главного меню появился реальный счётчик **«Онлайн сейчас»**.
- Сервер считает активные WebSocket-подключения к онлайн-режиму.
- Число обновляется автоматически примерно каждые 10 секунд, а также при возврате в окно игры.
- Если сервер временно недоступен, показывается «—», а не неверное число.

## Сохранено без изменений
- NA STUDIO заставка.
- Онлайн-партии, синхронизация, reconnect и реванш.
- Бот, локальная игра, настройки и статистика.

Запуск: `npm install` → `npm start`.
