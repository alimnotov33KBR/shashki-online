# Шашки v5.2.1 Online PRO — NA STUDIO + Ratings

Основа: стабильная v5.2.0 с NA STUDIO, Reconnect FIX и счётчиком онлайн.

## Новое
- Игроки могут поставить 1–5 звёзд и оставить комментарий до 300 символов.
- Кнопка оценки доступна в главном меню и после окончания партии.
- Оценки отправляются на сервер без IP-адреса в сохранённых данных.
- Встроенная панель владельца показывает среднюю оценку, количество голосов, распределение 1–5★ и последние комментарии.
- Панель владельца скрыта от обычных игроков и появляется только по адресу `/?owner=1`.
- Просмотр данных защищён серверным секретом `ADMIN_KEY`.

## Как включить панель владельца на Render
1. Render → shashki-online → Environment.
2. Добавить переменную `ADMIN_KEY` со своим длинным секретным паролем.
3. Сохранить и дождаться redeploy/restart.
4. Открыть `https://shashki-play.com/?owner=1`.
5. Нажать «Оценки игроков» и ввести тот же `ADMIN_KEY`.

Секрет не зашит в HTML и не показывается обычным игрокам.

## Хранение оценок
Оценки сохраняются в `ratings.json` на файловой системе запущенного сервера. На Render Free файловая система непостоянная: данные могут исчезнуть после redeploy/restart. Для постоянного архива в следующей версии лучше подключить внешнюю базу данных (например PostgreSQL/Supabase).
