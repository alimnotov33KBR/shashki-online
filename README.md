# Шашки v5.2.2 Online PRO — Persistent Ratings

Основа: стабильная v5.2.1 с NA STUDIO, Reconnect FIX, счётчиком онлайн и оценками игроков.

## Новое
- Оценки теперь могут храниться постоянно в PostgreSQL.
- Таблица `game_ratings` и индекс создаются сервером автоматически при первом запуске.
- Сохраняются все оценки, комментарии, имя игрока, режим, версия и дата.
- Панель владельца работает как раньше через `/?owner=1` и `ADMIN_KEY`.
- В ответ панели владельца сервер также сообщает тип хранилища (`postgresql` или `file`).
- Если в проекте есть старый `ratings.json` и база пуста, сервер один раз попробует перенести эти оценки в PostgreSQL.

## Что нужно настроить на Render
1. Создать PostgreSQL-базу у Render или другого PostgreSQL-провайдера.
2. В Web Service → Environment добавить переменную `DATABASE_URL` со строкой подключения к базе.
3. Оставить существующий `ADMIN_KEY` без изменений.
4. Сделать Deploy. Сервер сам создаст таблицу `game_ratings`.

При наличии `DATABASE_URL` оценки переживают redeploy/restart приложения, потому что находятся в отдельной базе данных.

## Резервный режим
Если `DATABASE_URL` не задан, игра продолжит работать и сохранит оценки в `ratings.json`, как v5.2.1. На Render Free этот режим не является постоянным.
