# Шашки v5.1.4 Online PRO — Reconnect FIX

Точечное исправление механизма восстановления соединения поверх v5.1.3.

## Что исправлено

- После возврата интернета клиент **не доверяет старому WebSocket**, даже если браузер всё ещё показывает `OPEN`: создаётся новый сокет и выполняется `resume` в ту же комнату по токену игрока.
- Добавлен watchdog `ping/pong`: если сокет выглядит открытым, но сервер перестал отвечать, он принудительно закрывается и запускается переподключение.
- Добавлена обработка браузерных событий `offline` / `online`.
- При возврате вкладки из фона дополнительно проверяется живость WebSocket.
- Окно восстановления игрока на сервере увеличено с 20 до 60 секунд, чтобы мобильная сеть успела вернуться.
- После `resume` сервер по-прежнему отправляет последнее подтверждённое состояние доски и номер хода.
- Дизайн, правила, сильный ИИ, онлайн-ходы и реванш не менялись.

Версия: **5.1.4**.
