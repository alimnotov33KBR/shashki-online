# Шашки v5.1.3 Online PRO

Обновление онлайн-режима поверх v5.0.


## Исправление v5.1.3

- Исправлена ошибка «Ошибка синхронизации хода» в онлайн-партии.
- Каждый онлайн-ход теперь передаётся вместе с полным состоянием доски.
- Второе устройство восстанавливает позицию из подтверждённого состояния вместо повторного локального вычисления хода.
- Добавлен порядковый номер онлайн-ходов, чтобы игнорировать дубликаты и старые сообщения.
- Сервер контролирует очередность цвета и сбрасывает синхронизацию при новой партии и реванше.

## Что нового

- После партии можно предложить реванш.
- Второй игрок получает предложение и может принять или отказаться.
- Новая партия начинается одновременно у обоих игроков.
- В реванше игроки меняются цветами.
- Предложение реванша можно отменить.
- Имена игроков в онлайн-комнате.
- Имя запоминается на устройстве.
- Кнопка приглашения соперника.
- Приглашение можно отправлять ссылкой вида `?room=ABCDE`.
- При открытии ссылки код комнаты автоматически подставляется.
- В ожидании отображаются игрок, цвет и подключение соперника.
- В партии статус показывает имя того, чей сейчас ход.
- Сервер передаёт имена игроков вместе с состоянием комнаты.
- Подготовлена поддержка сообщения о сдаче (`resign`) для следующего UI-шага.

## Локальный запуск
```bash
npm install
npm start
```
Открыть: http://localhost:3000

## Render
Build Command:
```bash
npm install
```
Start Command:
```bash
npm start
```

После загрузки этих файлов в тот же GitHub-репозиторий Render может автоматически выполнить новый Deploy.


## Исправление v5.1.3
- Добавлен WebSocket heartbeat на сервере (ping/pong каждые 25 сек).
- Клиент отправляет служебный ping каждые 15 сек, чтобы соединение комнаты не считалось простаивающим прокси/мобильной сетью.
- Обработчики WebSocket привязаны к конкретному экземпляру соединения, поэтому закрытие устаревшего сокета не сбрасывает активную онлайн-сессию.
