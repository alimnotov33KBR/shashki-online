# Шашки v5.2.3 Online PRO — Neon Free Ratings

Эта сборка сохраняет оценки игроков в бесплатной внешней PostgreSQL-базе Neon.

## Что нужно на Render

1. Создать бесплатный проект Neon.
2. В Neon открыть Connect и скопировать **Pooled connection string**.
3. В Render → shashki-online → Environment добавить переменную:
   - Key: `DATABASE_URL`
   - Value: полная строка подключения Neon (она заканчивается параметром `sslmode=require` или содержит его).
4. Сохранить изменения и дождаться нового Deploy.

`ADMIN_KEY` оставить как есть.

## Как работает

При запуске сервер сам создаёт таблицу `game_ratings`, если её ещё нет. Оценки и комментарии записываются в Neon и сохраняются независимо от перезапусков и новых Deploy на Render.

Если `DATABASE_URL` не задан, сервер временно использует локальный `ratings.json`; на бесплатном Render это не является постоянным хранилищем.

## Безопасность

Не добавляйте `DATABASE_URL` или пароль базы в GitHub. Строка подключения должна храниться только в Environment Variables на Render.
