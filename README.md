# Шашки v5.0 Online

В этой версии добавлена настоящая игра через интернет.

## Что есть
- Режим «Онлайн через интернет».
- Создание комнаты с коротким кодом.
- Подключение второго игрока по коду.
- Создатель играет белыми, подключившийся — чёрными.
- Ходы синхронизируются через WebSocket.
- Работают обязательные взятия и серии взятий.
- Уведомление, если соперник отключился.
- Перезапуск партии для обоих игроков.
- Все офлайн-режимы и Strong AI сохранены.

## Как запустить на компьютере
1. Установите Node.js 18+.
2. Откройте терминал в этой папке.
3. Выполните:
   npm install
   npm start
4. Откройте http://localhost:3000

Важно: для онлайн-игры НЕ открывайте index.html двойным кликом.
Нужно заходить через адрес сервера.

## Как играть через интернет
Сервер нужно разместить в интернете (Render, Railway, Fly.io, VPS и т.п.).
После публикации игроки открывают один и тот же HTTPS-адрес.
Первый создаёт комнату и отправляет код второму.

## Порт
По умолчанию 3000. На хостинге используется переменная окружения PORT.
