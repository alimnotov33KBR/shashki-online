# Шашки v5.1.3 Online PRO

Исправленная сборка поверх v5.1.2.

## Исправление соединения
- Сервер не удаляет игрока мгновенно при кратком обрыве WebSocket: есть 20 секунд на восстановление.
- Клиент автоматически переподключается к той же комнате по защищённому случайному токену сессии.
- При восстановлении сервер возвращает цвет, имена игроков, номер хода и последнее подтверждённое состояние доски.
- Добавлен WebSocket heartbeat: серверный ping/pong и клиентский служебный ping.
- Старый экземпляр WebSocket не может сбросить состояние нового соединения.
- `opponent_left` отправляется только после окончания окна переподключения либо явного выхода.
- HTML title, меню, package.json и серверная строка версии синхронизированы на v5.1.3.

Сохраняются функции v5.1.2: синхронизация полного состояния доски, порядковый номер ходов, имена игроков, приглашения по ссылке и реванш по согласию.
