# Шашки v5.1.6 Online PRO — NA STUDIO

Финальная сборка на базе проверенной v5.1.4 Reconnect FIX.

## Изменение
- Новая полноэкранная заставка NA STUDIO в оранжево-бронзовом стиле.
- Заставка показывается 3 секунды и может быть пропущена касанием/кликом.
- Работает на компьютере и телефоне.
- Онлайн-механизм, переподключение, синхронизация, реванш и игровая логика не изменялись.

## Запуск
```
npm install
npm start
```
