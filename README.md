# Шашки v5.1.5 Online PRO — NA STUDIO

Готовая сборка на базе проверенной v5.1.4 Reconnect FIX.

## Новое
- Добавлена полноэкранная фирменная заставка **NA STUDIO** в чёрно-золотом стиле игры.
- Заставка автоматически исчезает примерно через 2.8 секунды; её можно пропустить касанием/кликом.
- Адаптирована для телефона и компьютера.
- Онлайн-механизм, reconnect, синхронизация, реванш и игровая логика v5.1.4 не изменялись.

## Запуск
```bash
npm install
npm start
```

Для Render: Build Command `npm install`, Start Command `npm start`.
